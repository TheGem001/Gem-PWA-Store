# 💎 Gem Store

**The Official PWA Marketplace for Gem Labs**

![Version](https://img.shields.io/badge/version-1.7.0-black)
![Status](https://img.shields.io/badge/status-inactive-red)

**Gem Store** is a minimalist application directory designed to unify the Gem Labs ecosystem. It functions as a Progressive Web App (PWA), allowing users to browse and launch Gem Labs utilities from a single interface.

⚠️ **Note:** This project is **Currently Inactive**.

🔗 **Live Demo:** [https://thegem001.github.io/Gem-PWA-Store/](https://thegem001.github.io/Gem-PWA-Store/)

---

## 🚀 Features

* **Unified Hub:** Access tools like *Splitify* and *Soul Calculator* in one place.
* **PWA Experience:** Installable to your home screen with offline support via Service Workers.
* **Gem Mono Design:** A minimalist Black & White palette focusing on glassmorphism and smooth animations.
* **Dynamic Catalog:** Apps are managed via a simple `apps.json` structure for easy updates.
